# 2027 巴塞隆納家庭旅遊

家庭共享行程網站（繁體中文）。以單一 `index.html` 提供四個分頁：行程總覽、每日行程、住宿與交通、待辦事項。

## 正式網站

GitHub Pages 首次設定：至 **Settings → Pages → Build and deployment**，選擇 **Deploy from a branch**，Branch 設為 **main**，Folder 設為 **/(root)**，按 **Save**。

發布完成的網址： https://tinweng-TT.github.io/barcelona-family-2027/

## 日後更新

每次修改 `main` 分支中的 `index.html` 並提交，GitHub Pages 就會自動重新部署，不需要付費 Lovable 點數。請在 ChatGPT 告知行程更新，由已授權的 GitHub 工具協助更新。

## 隱私與待辦

這是**公開**網站。不要加入護照號碼、機票號碼、訂房確認碼或私人聯絡資訊。待辦勾選進度保留在每個裝置自己的瀏覽器，不會自動同步到其他家人的手機。
